# Проект rag системы для локально работающих нейросетей через ollama

Есть возможность проиндексировать файлы заранее или они будут индексироваться и сохраняться прямо во время выполнения программы.

Проидексировать заранее файлы можно в index.py, а спросить вопросы с использованием rag можно либо по программированию в main.py, либо из wiki в wiki.py.
